# Финальный проект 1 семестра

REST API сервис для загрузки и выгрузки данных о ценах. Простой уровень сложности.

## Требования к системе

- **ОС**: Windows, Linux, MacOS
- **Go**: 1.20 и выше
- **PostgreSQL**: 13 и выше
- **Кампуктер**: 2 ядра, 2 гига, игровая видеокарта

## Установка и запуск

1. Создание базы данных:
   ```bash
   psql -U validator -d postgres -c "CREATE DATABASE project_sem_1";
   ```
2. Установка зависимостей и подготовка БД:
   ```bash
   ./prepare.sh
   ```
3. Запуск приложения:
   ```bash
   ./run.sh
   ```

## Тестирование

Запуск тестов:
   ```bash
   ./scripts/tests.sh 1
   ```
